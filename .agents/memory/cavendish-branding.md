name: Cavendish branding
description: Source-of-truth branding decisions for the wallet interface
---

Use the feather-arrow mark in the Cavendish logo asset as the source of truth for the app logo, favicon, and wallet branding. Keep the lime-on-black visual system as the primary treatment; reserve other colors for semantic states.

**Why:** The reference direction replaced the earlier C-and-leaf mark and established a distinct, consistent Cavendish identity.

**How to apply:** Reuse the existing feather-arrow logo asset for new branded surfaces instead of recreating the earlier inline monogram.
